# 🏡 Smart Housing Price Analytics using Machine Learning

## 📌 Overview

This project develops machine learning models to predict residential property prices using the **King County Housing Dataset**.

The project focuses on applying data analytics and predictive modelling techniques to understand the factors influencing housing prices while building accurate and interpretable prediction models.

---

# 🎯 Objectives

- Perform Exploratory Data Analysis (EDA)
- Clean and preprocess housing data
- Engineer meaningful predictive features
- Develop machine learning prediction models
- Compare model performance
- Identify important price-driving factors
- Build an end-to-end housing price prediction pipeline

---

# 📂 Dataset

**Source**

King County Housing Dataset

Features include:

- Bedrooms
- Bathrooms
- Living Area
- Lot Size
- Floors
- Waterfront
- View
- Condition
- Grade
- Year Built
- Location
- Property Price
